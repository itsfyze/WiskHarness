# WiskHarness 0.7.3 migration

## Update from beta.7

Open **Settings → Updates**, check for updates and choose **Update**. The app uses the official GitHub release and verifies the package digest before installation. Setup updates the existing installation. Portable replaces the executable in its current writable location. WiskHarness reopens when the installer or replacement verifies startup.

Chats, task checkpoints, workspaces, model preferences, themes, Obsidian settings, permissions and updater settings use the existing profile. Vibe keeps its native state inside a per-chat subdirectory. Existing chats remain readable and can continue from their WiskHarness transcript. An explicit Goose preference stays selected. To select another engine, open **Settings → Agent execution**.

## Runtime

Electron starts the local API, loads the renderer and handles the Windows update handoff. The API scopes each session to its workspace and runs permission checks, file tools, shell tools, search and review. It sends chat and activity events to the renderer over SSE.

Mistral Vibe ACP owns inference orchestration, native session loading and compaction. WiskHarness converts Vibe's OpenAI-compatible requests to Ollama native chat so it can set the actual model context and read provider timings. Only registered tool schemas reach the model. WiskHarness turns a structured call into a fixed Vibe MCP invocation and checks the arguments and permissions before dispatch. The bridge denies unregistered calls and does not interpret prose as commands. The Windows build pins and verifies the official Vibe ACP 3.1.5 archive. The first Vibe turn verifies and extracts that archive into the WiskHarness profile.

Agent mode supports development tools. Plan uses a read-only tool set when a compatible local Vibe model is available. Ask, cloud conversations and the Plan compatibility path use text only. The existing native Ollama engine supports JSON compatibility and Goose remains selectable.

## Settings and review

New profiles use the Ink theme. Paper and the original themes remain available. Settings can configure a remote Ollama address, per-model Vibe options, search and explicitly trusted MCP servers. Ollama discovery uses the selected endpoint, with no Mistral account required. Vibe 3.1.5 requires native Ollama tool support and a context of at least 13,334 tokens. Use the native Ollama engine for smaller context presets or models that need JSON compatibility.

The Changes panel compares the active workspace to its start-of-turn snapshot. Direct file writes and edits can be attributed and reverted when WiskHarness can prove their contents and the files still match. Shell-generated files and concurrent workspace changes can appear as observed workspace changes. Binary and large files have metadata only. Agent terminal activity is also available in saved tool results.

The composer shows estimated live generation speed during streaming and the last measured Ollama rate when idle. Context and speed readouts are unavailable when the provider does not supply the necessary data.

## Search and permissions

Use Brave Search with a key or a trusted SearXNG instance with JSON enabled. Public page retrieval rejects private addresses and unsafe redirects. A configured 127.0.0.1 SearXNG URL is available only to the search tool. The Internet access switch controls built-in web tools and remote MCP availability. Windows permissions apply to external programs and approved shell commands.

The MCP manager accepts configured local executables and Streamable HTTP endpoints. Connection tests execute the selected server or contact its endpoint. WiskHarness encrypts credentials with Windows DPAPI and requires approval before sending tool arguments to a configured external server. Repository MCP configurations stay outside the managed list.
